## Architectural screen

Neither proposal requires a new shallow module, pass-through API, endpoint, solver, or importable internal. Both keep canonical requests and draft storage private to the existing board owner.

Both avoid information leakage by deriving force conclusions from the accepted shared review. Reject any implementation that copies force-sign policy into walkthrough code or repeats the default numerical request in a new constant.

A avoids temporal decomposition. Its explanations follow the existing page without introducing progress state. B's four steps remain presentation state, but they add a second way to navigate the same task. That is a maintenance cost rather than a numerical correctness defect.

Neither may split ownership of accepted results. Derive current, stale, failed, and unsupported explanations from existing state. Do not store another result or current-result flag.

Neither needs a hand-synced scenario library. Retain `data.default_request` before draft restoration and reuse the ordinary form submission for the gap trial.

## Conditions for implementation

- Name the actual ULX3S U1 pad J16 and its 400 µm lower copper. Other pads remain unsolved context.
- Name 40 and 56 nL as hypothetical liquid volumes. The 300 µm and 330 µm values are held gaps, not alternative pad diameters.
- State that restoring lateral force without upward separation is the declared fixture objective. It is not a universal free-package quality rule.
- Load the example explicitly. Preserve a restored custom draft until the user chooses replacement.
- Change only held gap in the 330 µm trial. Submit through the existing validation and native computation path. Disable native trial actions when the engine is unavailable or the source selection is unsupported.
- Obtain forces, preferred volume, and outcome text only from the accepted current response. Before acceptance, describe the experiment rather than promise a reversal.
- Invalidate the explanation, meshes, and downloads on any input or selection edit. Reject late responses through the existing revision and source checks.
- Keep physical force accuracy unqualified. A sampled gap change does not establish a manufacturing uncertainty bound.
- Identify the existing 200 µm force fixture as requiring adaptation for this 400 µm specimen. Link the separate 220 versus 270 µm height coupon without treating it as force validation.
