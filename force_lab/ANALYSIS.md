# Prospective force analysis

The unit of replication is one independently prepared molten bridge. Separate specimens serve x and z. Three preparation blocks contain two independent paired replicates per axis, offset and volume. Reversal or dwell samples describe one specimen and do not increase its sample count.

`protocol.json` owns endpoints, acceptance thresholds, independent allocation and numerical planning inputs. `inputs.csv` owns measured geometry, liquid volume and transverse alignment per specimen. `metadata.json` owns independently measured alloy, liquidus, temperature, surface tension, density and commissioning evidence. `calibration.json` owns force-axis calibration, corrected standard measurement uncertainty, coverage justification and endpoint covariance. `input_covariance.json` owns standard input covariance, including shared systematic terms. Blank templates contain no invented observations. Revision 2 requires explicit source units, cross-domain covariance and transverse-alignment fields. Earlier incomplete records cannot be qualified under this revision.

`analyze.py plan OUTPUT` records unqualified example predictions and local numerical sensitivities. It makes 20 distinct native requests at the 120 um, 5/7 nL design. Gap and volume use central differences. Other inputs use forward differences. Both rim diameters remain independent parameters. Density is included. This Jacobian is a local linearization, not a physical uncertainty interval or a bound on nonlinear behavior. Each force change is compared with the sum of its two recorded refinement changes. An unresolved sensitivity retains its raw Jacobian but produces a null one-source allowable limit. An algebraic limit outside the registered 2 percent relative-U domain also produces null. A nearly zero density sensitivity cannot justify an enormous density tolerance.

`verify-plan DIRECTORY` checks the complete expected receipt and source member set, input hashes and exact requests. It derives the cases again from those receipts, then independently recomputes every target, sensitivity qualification, resolution flag, single-source limit and scenario conclusion with the same pure arithmetic used for generation. Edited JSON conclusions fail verification even if the file is rewritten as valid JSON. This is portable static numerical-record verification. It requires the matching analyzer/model source and archived receipts, not an installed engine. Each completed receipt must identify exactly the engine archived in the plan; failed attempts without an engine identity remain failure evidence. Verification does not rerun native computation, authenticate physical inputs or establish an external timestamp.

`freeze INPUT_DIRECTORY OUTPUT` reads each supplied file once, hashes and snapshots those exact bytes, rejects any pre-existing confirmatory outcome, and runs fresh central predictions and sensitivities at measured inputs. It requires independent material evidence and completed hot commissioning. The freeze includes numerical receipts and a manifest. `verify FREEZE` rejects modified files, code identities or receipt/archived-engine contradictions. `score FREEZE OUTCOMES OUTPUT` scores later observations without refitting. Both operate on the registered frozen bytes without requiring a local engine or claiming native replay. Fresh `plan` or `freeze` computations require engine setup; rebuilding at another path does not replace the archived producer identity. The scorer combines signed sources across input and measurement domains before quadrature and adds conservative numerical refinement terms. Unknown calibration or covariance prevents freezing. Unknown wetting, stability or observed transverse alignment makes scoring inconclusive. A result concerns these isolated fixed-rim hot-joint endpoints only.

A completed freeze is an immutable, locally integrity-checked record. SHA-256 is not a trusted external timestamp or protection against an adversary who rewrites all files. Register the manifest digest with the independent lab before acquiring confirmation outcomes. A changed process requires a new freeze and fresh confirmation specimens.

Source coefficients multiply the named source's standard uncertainty into each variable's native units. A geometry-only source may use mm with dimensionless coefficients. A temperature source uses `source_unit="K"`; its coefficients convert K to each affected input's units or to corrected force in uN. Use the same source ID, standard uncertainty and unit in both files when one physical source affects both prediction and corrected measurement. Conflicting standard uncertainties or units for one ID reject the freeze. Differently named sources are treated as independent only after `unlinked_sources_independent=true` and `cross_domain_independence_evidence` explicitly document that assertion. Unknown covariance must first be resolved or conservatively bounded by a prospective protocol revision.

For each endpoint the residual coefficient of a source is its corrected-measurement coefficient minus its predicted-force coefficient. The scorer sums the squared standard residual contributions. Equal signed coefficients can cancel; opposite coefficients add. A common source remains common across all specimens. The separate marginal input and force uncertainties remain visible, and the individual input and force capability gates still apply. The decomposition guarantees a positive semidefinite covariance but cannot establish completeness or independence. The lab's evidence and independent review remain required.

Independently measure relative transverse displacement before freezing and again during the confirmation dwell. Record `transverse_offset_mm` and its positive expanded `transverse_U_mm` in inputs. Record `actual_transverse_offset_mm` and `actual_transverse_U_mm` in outcomes. Both must satisfy `abs(y) + U_y <= 0.0005 mm` with the justified k=2 coverage. Missing frozen values reject freezing. Missing or excessive confirmation values are inconclusive. This initial apparatus-domain bound keeps the experiment near the prescribed x-z plane. It does not establish physical accuracy at that bound, model arbitrary y offsets, or replace a force-budget qualification. Tighten it prospectively if commissioning identifies a consequential transverse effect.

The selected endpoints include lateral volume contrast, absolute lateral force and normal force. A shared lateral bias may cancel in the contrast. It cannot qualify the overall force model. The scorer retains separate endpoint, individual and preparation-block assessments and rejects such cancellation in `overall_status`.
