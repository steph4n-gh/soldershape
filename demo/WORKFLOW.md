Swarm coverage uses two independent design candidates and a fresh judge. Rank all. Root owns numerical experiments, integration and browser verification. Each delegate owns one separate report, not shared application files. All roles inherit the configured parent model. This is not cross-model agreement.

## Done predicate

Deliver one visually compelling local demo that lets a process engineer inspect a consequential engineering tradeoff with actual native computation. A real or proposed board must be identified accurately. Preserve unsupported geometries and failures. No physical qualification, array reflow dynamics, solder-bridge prediction or customer value may be invented. Use the existing numerical engine and real export path. Demonstrate the running demo and an independently reproducible result.

## Scope and throughput checkpoint

First inspect existing extreme cases and run a bounded competence probe. Compare two structurally distinct demo designs before adding code. Prefer a small native-computed case gallery or a focused experiment over a new simulator. Cap the first numerical probe at six cases. Broaden only when a measured result makes the extra cases useful. Keep the original lab package and historical evidence unchanged. No fabrication, orders, vendor messages or deployment.

## Before-code acceptance

1. The chosen demo must show at least one consequence that a nominal aligned height formula does not answer.
2. Every displayed quantitative result must map to a normalized request and native receipt. Recorded cases must be labeled recorded and replayable. Live cases must compute through the existing solver.
3. Failed or model-scope-inconclusive cases remain visible and cannot receive a favorable decision.
4. The visible board and single-joint model must use declared consistent geometry. Any array repetition is illustrative, not a coupled calculation.
5. The demo must support a complete inspect, compare and export workflow, with its simplest analytical substitute and limits explicit.
6. Verify the real browser and actual downloaded archive, then run proportionate existing checks and a fresh adversarial review.
