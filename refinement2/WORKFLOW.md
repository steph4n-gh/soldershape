Definition of done. A user can understand a computed comparison without decoding raw signed values, recognize the same quantities when moving between µm/nL and mm/mm³ displays, and download an accurate standalone numerical review that remains useful without the application. Blocked/failure/scope outcomes remain blocked, old evidence remains immutable, and edits remove current takeaways and review exports. Actual browser use and downloaded artifact checks establish completion.

Scope. The existing Board/Joint core loop, minimal shared presentation and evidence export code, unit cues, and proportionate tests. No solver, study algorithm, physical claim, new simulation feature, new application framework or persistence redesign. Historical archives and the user's existing tab are preserved.

Throughput. Root owns browser baseline, integration and final verification. One source explorer grounds the seams. Two bounded whole-shape designs compete only for the new review surface. Implementation owners have disjoint files. An independent review checks claims and failure handling. Reuse the existing numerical and state checks, then run only newly justified artifact and native gates.

Gates. Fresh reference/candidate comparison, opposite offset sign, zero offset, normal-load mode, failed/scope outcomes, exact unit conversions, export/ZIP agreement, HTML escaping, edit invalidation, keyboard/narrow layout, existing saved work and source/release hashes.
